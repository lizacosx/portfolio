## Sobre o projeto

Este site é meu espaço para apresentar quem sou como desenvolvedora front-end e reunir projetos em uma experiência visual responsiva. A interface foi construída com HTML, CSS e JavaScript, com foco em tipografia, cores, movimento e navegação simples.

## Recursos

- Layout adaptado para celular e computador.
- Alternância entre tema claro e escuro.
- Idioma em português (Brasil) e inglês.
- Preferências de tema e idioma salvas no navegador.
- Gráfico de linguagens dos repositórios públicos do GitHub, atualizado a partir da API pública.
- Cartões de projetos preparados para receber links.
- Atalhos para Instagram, GitHub, e-mail e LinkedIn.
- Animações com suporte à preferência de movimento reduzido do sistema.

## Tecnologias

- **HTML5** para a estrutura e o conteúdo.
- **CSS3** para o visual, responsividade, temas e animações.
- **JavaScript** para as interações e a consulta à API do GitHub.

## Rodar localmente

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Inicie o `index.html` com a extensão **Live Server**.

O Live Server inicia um servidor local para a página. Ele também permite que o navegador consulte a API pública do GitHub para montar o gráfico de linguagens.

## About the project

This website is my space to introduce myself as a front-end developer and bring my projects together in a responsive experience. The interface is built with HTML, CSS, and JavaScript, with a focus on typography, color, motion, and clear navigation.

## Features

- Responsive layout for mobile and desktop.
- Light and dark themes.
- Portuguese (Brazil) and English language options.
- Theme and language preferences saved in the browser.
- A chart of languages used across my public GitHub repositories, loaded from the public API.
- Project cards ready for links to future work.
- Shortcuts to Instagram, GitHub, email, and LinkedIn.
- Animations that respect the system's reduced-motion preference.

## Built with

- **HTML5** for page structure and content.
- **CSS3** for styling, responsive layouts, themes, and animations.
- **JavaScript** for interactions and fetching GitHub API data.

## Run locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Start `index.html` with the **Live Server** extension.

Live Server runs the page on a local web server. This also lets the browser request data from the public GitHub API to build the language chart.
